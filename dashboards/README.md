# Dashboard index

Every dashboard this repository knows about: the ones kept here, and the ones kept in their own
repositories and indexed in the register.

Some dashboards ship as part of a larger application, where the dashboard and the exporter that
feeds it are versioned together and would drift if copied here. Those are indexed rather than
held, so they can be found alongside the dashboards in this tree.

Adding one:

- **A dashboard that works on the RHOAI Monitoring Stack alone** goes in a directory here, with
  a `metadata.yaml` describing it for the index. See the
  [contribution guide](https://rh-aiservices-bu.github.io/rhoai-community-dashboards/modules/main/contributing.html).
- **A dashboard that needs its own exporter, recording rules or operator** goes in
  [`register.yaml`](./register.yaml) as an entry under its repository.

Either way the same bar applies: no credentials, no customer identifiers, no internal endpoints,
and the required metrics documented.

The region below is generated by `validation/scripts/generate_dashboard_index.sh` from
`metadata.yaml` and `register.yaml`. Editing it by hand is pointless - the next run overwrites
it. See [Dashboard Register](https://rh-aiservices-bu.github.io/rhoai-community-dashboards/modules/main/dashboard-register.html)
in the full documentation for why the split exists and what belongs where.
